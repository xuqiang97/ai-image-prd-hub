## 业务背景和价值

美工版、运营版 AI 生图已支持在现有“LinkFox子模型”下拉中选择谷歌香蕉、GPT图片2、LinkFox自研模型V1、万相2.7等子模型，并在 LinkFox 计划生成张数大于 `0` 时调用商品套图建任务接口。

当前系统实际调用的 V3 接口为 `/linkfox-ai/image/v2/make/productMarketMaterialV3`。LinkFox 已将 V3 接口文档从常规文档目录下线并停止维护该版本，现已取得 LinkFox 技术提供的商品套图 V3 分享文档；新增模型仍需迁移至 V4 接口 `/linkfox-ai/image/v4/make/productMarketMaterial`。LinkFox 对接研发已确认 V4 是 V3 的后续优化版本，可直接切换；研发需结合 V3 分享文档、现网真实 V3 请求和响应与 V4 官方文档完成字段和响应兼容核对。

在本次接口核对过程中，确认 LinkFox 已调整第三方子模型的算力计费口径：由原先不区分参考图数量的固定价格，调整为根据请求中 `imageList` 的实际数量区分单参考图和多参考图价格；`AIDRAW_EDIT` 对应的“LinkFox自研模型V1”不参与分档，仍统一为 `20` 算力/张。当前页面仍展示旧的固定价格，需同步更新，避免用户在选择 GPT图片2高品质等高算力模型时缺少准确的成本参考。

本期在不改变现有页面结构和交互的前提下完成接口升级、新子模型接入及算力文案更新，并通过显式传入分辨率和素材宽高比，降低上游默认值后续变化对生成结果和算力成本的影响。

## 需求概述

1. 美工版、运营版所有 LinkFox 商品套图建任务统一由 V3 切换至 V4，上线后不再调用 V3，也不在 V4 失败时回退旧接口。
2. 在现有 LinkFox 子模型下拉末尾新增 `Seedream 5.0 Pro`，接口传参为 `provider=SEEDREAM5_PRO`、`resolution=2K`，不传 `quality`。
3. `BANANA_2_LITE` 因仅支持 1K、不满足业务固定 2K 的要求，本期不接入。
4. 更新全部现有 LinkFox 子模型的算力展示：第三方模型静态展示单参考图和多参考图两档价格，LinkFox自研模型V1继续展示固定价格；页面不根据当前图片数量动态切换文案。
5. 对 `resolution`、`aspectRatio` 执行显式传参，不依赖 LinkFox 默认分辨率或默认素材宽高比。

本需求不新增页面、字段位置或复杂交互，不需要单独制作 HTML 原型。

## 功能需求

### 1. 商品套图建任务接口升级

接口沿革和本期处理如下：

| 接口版本 | 接口地址 | 本期处理 |
|---|---|---|
| V2 | `/linkfox-ai/image/v2/make/productMarketMaterialV2` | 历史接口，不涉及改造，不得误调用。 |
| V3 | `/linkfox-ai/image/v2/make/productMarketMaterialV3` | 当前现网接口，本期上线后停止调用。 |
| V4 | `/linkfox-ai/image/v4/make/productMarketMaterial` | 本期统一切换的新建任务接口。 |

处理规则：

1. 必须替换完整接口地址，不得仅修改路径中的版本数字。V3 虽命名为 V3，但路径前半段仍为 `/image/v2/`，且方法名以 `V3` 结尾；V4 同时修改路径版本并取消方法名版本后缀。
2. 美工版、运营版共享的 LinkFox 商品套图建任务后端链路统一切换 V4，各业务入口无需分别实现一套接口切换逻辑。
3. V4 请求失败时沿用现有任务失败处理，不自动回退 V3、V2或其他 LinkFox 子模型。
4. 本期仅调整商品套图建任务接口；现有结果查询、轮询、状态判断、任务流转、结果关联和图片落库逻辑保持不变，不新增成功状态门槛、重试机制或状态规则。
5. 上线前由 V3 已创建但尚未完成的任务，继续沿用现有查询链路获取结果，不因建任务接口切换而中断。
6. 研发需使用 V3 分享文档、现网真实 V3 请求和响应与 V4 官方文档逐项核对字段名称、层级、类型、必填规则、鉴权、请求头、任务 ID 及错误返回。V3 分享文档与现网实际调用不一致时，以现网真实 V3 请求和响应作为当前行为基线，并先反馈产品或 LinkFox 确认，不得仅根据分享文档或字段名称自行改变业务口径。
7. 上线前确认生产账号已开通 V4 和 `SEEDREAM5_PRO` 调用权限；上线后通过出站请求日志确认不再产生 V3、V2 建任务调用。

### 2. LinkFox子模型选项与算力展示

沿用现有 LinkFox 子模型下拉、默认值、选中逻辑和字段位置，在万相2.7之后追加 Seedream 5.0 Pro。完整选项如下：

| optionCode | 页面展示文案 | provider | quality | resolution | 单参考图算力/张 | 多参考图算力/张 |
|---|---|---|---|---|---:|---:|
| `BANANA_PRO_2K` | 谷歌香蕉1Pro（单参考图50，多参考图60算力/张） | `BANANA_PRO` | 不传 | `2K` | 50 | 60 |
| `BANANA_2_2K` | 谷歌香蕉2（单参考图50，多参考图60算力/张） | `BANANA_2` | 不传 | `2K` | 50 | 60 |
| `GPT_2_IMAGE_LOW_2K` | GPT图片2低品质（单参考图15，多参考图25算力/张） | `GPT_2_IMAGE` | `low` | `2K` | 15 | 25 |
| `GPT_2_IMAGE_MEDIUM_2K` | GPT图片2中品质（单参考图50，多参考图60算力/张） | `GPT_2_IMAGE` | `medium` | `2K` | 50 | 60 |
| `GPT_2_IMAGE_HIGH_2K` | GPT图片2高品质（单参考图150，多参考图160算力/张） | `GPT_2_IMAGE` | `high` | `2K` | 150 | 160 |
| `AIDRAW_EDIT_2K` | LinkFox自研模型V1（20算力/张） | `AIDRAW_EDIT` | 不传 | `2K` | 20 | 20 |
| `WAN2_7_2K` | 万相2.7（单参考图25，多参考图30算力/张） | `WAN2_7` | 不传 | `2K` | 25 | 30 |
| `SEEDREAM5_PRO_2K` | Seedream 5.0 Pro（单参考图40，多参考图50算力/张） | `SEEDREAM5_PRO` | 不传 | `2K` | 40 | 50 |

展示规则：

1. 第三方子模型统一静态展示单参考图和多参考图两档价格；下拉选项和选中后的文案一致，不根据当前 `imageList` 数量动态切换。
2. LinkFox自研模型V1不区分单多参考图，继续展示“20算力/张”。
3. 页面算力仅用于向用户提供选择参考，系统不新增本地扣费计算，也不保存任务创建时的价格快照；实际扣费由 LinkFox 按官方规则执行。
4. 无缓存或缓存不可用时，默认选项继续为谷歌香蕉1Pro；本期不因新增选项或价格文案变化调整默认模型。
5. `optionCode` 继续用于前端选项识别和 localStorage 缓存，不作为 LinkFox 接口字段；新增 Seedream 5.0 Pro 后可按 `SEEDREAM5_PRO_2K` 正常缓存和回显。
6. `BANANA_2_LITE` 仅支持 1K，本期不增加该选项，也不得将其作为 Seedream 5.0 Pro或其他子模型的失败降级模型。

### 3. 页面说明文案

保持现有字段标题、官方算力说明链接、蓝色多模型提示、字段位置和下拉交互不变。

字段标题继续为：

> LinkFox子模型（查看官方算力说明）：

“查看官方算力说明”继续新标签页打开：

https://open.ziniao.com/docSupport?docId=176

蓝色提示继续为：

> **多模型适配**：该字段仅 LinkFox 使用；自研、阿里绘蛙忽略此字段。

灰色说明调整为：

> 图片分辨率固定按2K生图；1张参考图按单参考图价格，2～5张按多参考图价格。页面算力仅供参考，实际以LinkFox官方最新说明为准。

展开下拉和选中后的输入框均需完整展示模型名称及关键算力信息，不得因文案变长而遮挡单多参考图价格。

### 4. 单多参考图计费口径

1. 参考图数量以提交给 LinkFox V4 的实际请求参数 `imageList` 的数组长度为准。
2. `imageList.length = 1` 时，LinkFox 第三方子模型按单参考图价格计费。
3. `imageList.length` 为 `2`～`5` 时，LinkFox 第三方子模型按多参考图价格计费。
4. `AIDRAW_EDIT` 对应的 LinkFox自研模型V1不参与分档，单参考图和多参考图均为 `20` 算力/张。
5. 页面同时展示两档价格，不根据当前参考图数量计算、切换或突出某一档价格。
6. 商品套图 V4 计费统一以 LinkFox 算力说明中“AI生图”章节的单多参考图价格表为准，不采用同一页面前部旧“商品套图”固定价格表。
7. 算力价格以 LinkFox 官方最新说明为准；提测和上线前需再次核对上述指定价格表与页面文案一致。

### 5. 显式传参规则

本期仅对分辨率和素材宽高比执行以下显式传参规则：

| 请求参数 | 显式传参规则 |
|---|---|
| `resolution` | 所有本期支持的 LinkFox 子模型统一显式传 `2K`，页面不开放 1K、4K 选择。 |
| `aspectRatio` | 当 `sellerTypeNum`、`sceneTypeNum`、`closeUpTypeNum`、`closeUpWhiteTypeNum` 任一大于 `0` 时，显式传 `1:1`；同一请求即使同时包含普通A+也照常传入，普通A+不受该字段控制。仅生成普通A+且上述数量均为 `0` 时，不传该字段。 |

`whiteBgTypeNum` 对应的白底图当前尚未接入，本期不新增该图片类型或对应数量字段。后续独立接入白底图时，已确认 `whiteBgTypeNum > 0` 同样需要显式传 `aspectRatio=1:1`。

### 6. 影响入口与兼容范围

直接改造点：

- 美工版、运营版共用的 LinkFox 商品套图建任务后端调用；
- 现有 LinkFox 子模型选项字典、算力展示文案及 `SEEDREAM5_PRO` 映射；
- 如任务配置、生成过程、图片结果、L3 标签或 BI 同步存在 provider 白名单，补充 `SEEDREAM5_PRO` 映射。

需要回归的业务入口：

- 美工版新增任务、批量导入任务、编辑任务后提交、复制重跑、批量复制重跑；
- 运营版新增任务、批量导入任务、编辑任务后提交、复制重跑、批量复制重跑；
- 美工版、运营版查看任务的 LinkFox 子模型只读回显；
- L3 沉浸式大屏当前 LinkFox 图片的子模型 Tag；
- 任务配置、生成过程、图片结果及 BI 子模型维度。

兼容规则：

1. 沿用原有 localStorage 的用户、业务端和缓存版本隔离规则；已有 `optionCode` 缓存继续有效，不清空、不迁移，也不因价格文案变化升级缓存版本。
2. 编辑、查看、复制重跑、批量复制重跑继续以任务已保存的子模型配置为准，不使用新增任务缓存覆盖。
3. 历史任务和历史图片不回刷价格或新增价格快照；历史 LinkFox 子模型兼容口径继续沿用 M-35698。
4. 历史任务执行复制重跑或批量复制重跑时继承原子模型配置，但新建任务请求统一通过 V4 发出，并按当前官方规则计费。
5. 任务列表页、L2 审核工作台继续不展示 LinkFox 子模型；本期不新增批量修改、子模型筛选、推荐标签或费用确认弹窗。
6. 自研、阿里绘蛙生成链路不读取、不传递 LinkFox 子模型字段，原有生成、查看和审核流程不受影响。

## 风险描述

| 风险 | 处理方式 |
|---|---|
| V3 分享文档可能经过后续补充，与现网实际 V3 能力存在版本差异 | V3 分享文档仅作为字段参考，以现网真实 V3 请求、响应和已保存 Postman 记录作为当前行为基线，与 V4 官方文档逐项核对；发现不一致时先反馈产品或 LinkFox 确认。 |
| 生产账号未开通 V4 或 Seedream 5.0 Pro | 提测和上线前使用生产同等权限账号完成真实建任务验证。 |
| 上游默认值后续调整导致生成规格变化 | 对2K分辨率和适用图片类型的1:1素材宽高比显式传参，不依赖默认值。 |
| 上游算力规则调整后页面文案滞后 | 页面保留“仅供参考、以官方最新说明为准”，提测和上线前再次核对官方价格表。 |
| 同一算力说明页面存在新旧两套商品套图价格 | 仅采用“AI生图”章节的单多参考图价格表，不采用旧“商品套图”固定价格表。 |
| 双档算力文案变长后展示不完整 | 回归下拉展开项和选中框，确保关键价格完整可见。 |
| V4 失败后错误降级导致模型或成本偏差 | 沿用现有失败处理，不回退 V3、V2或其他子模型。 |
