## 业务背景和价值

美工版、运营版均已上线独立的“查看已完成生图”页面，用于按任务分组回看已完成生图。两个页面及查询接口分别实现，但筛选结构一致，均区分任务维度和图片维度。

当前任务维度已支持普通搜索和批量搜索，图片维度已支持模型、图片类型、侵权禁售检测、AI生成人物检测等筛选，但存在以下不足：

1. 任务维度不能使用第三方任务 ID查询。
2. 图片维度不能使用图片名、第三方图片 ID或 L3现有组合第三方 ID查询。
3. 模型筛选只能选择 LinkFox、自研、阿里绘蛙等主模型，不能进一步筛选 LinkFox子模型。

本期补齐以上能力，便于业务根据第三方问题反馈材料快速定位对应任务和图片，并按 LinkFox具体子模型回查产出结果；查询继续受时间、其他筛选条件和现有数据权限约束。

## 需求概述

1. 美工版、运营版查看已完成生图的任务维度普通搜索新增第三方任务 ID匹配，现有批量下拉新增“第三方任务ID”。
2. 两版图片维度新增普通搜索和批量搜索，支持图片名、第三方图片 ID及组合第三方 ID精确查询；图片批量查询默认字段为“第三方ID”。
3. 图片维度新增“LinkFox子模型”筛选，支持现有8个子模型；主模型未选择 LinkFox 时字段置灰。
4. 美工版、运营版查询接口分别完成对应改造，查询关系、批量组件、权限、分页及异常处理口径保持一致。

本需求只扩展现有筛选和查询能力，不新增页面、弹窗或复杂交互，不调整列表图片卡片和 L3沉浸式大屏现有展示，不需要单独制作 HTML 原型。

## 功能需求

### 1. 影响入口和改造范围

| 业务端 | 左侧菜单 | 页面 | 直接改造范围 |
|---|---|---|---|
| 美工版 | 美工已完成生图 | 查看已完成生图（美工版） | 美工版筛选区、任务与图片查询逻辑、美工版独立查询接口 |
| 运营版 | 运营已完成生图 | 查看已完成生图（运营版） | 运营版筛选区、任务与图片查询逻辑、运营版独立查询接口 |

两版接口分别开发，但必须实现相同的新增能力和规则。现有状态子 Tab、排序、展示密度、任务分组、图片卡片、任务分页、查询、重置及 L3只读查看继续沿用现状。

筛选栏继续保持任务维度、图片维度两个逻辑分区。图片维度字段顺序固定为：模型 → LinkFox子模型 → 图片类型 → 侵权禁售检测 → AI生成人物检测 → 搜索 → 批量 → 查询 → 重置。新增字段在系统现有支持的页面宽度内不得重叠、遮挡或截断关键输入文案，【查询】【重置】按钮必须始终可见；空间不足时可在图片维度分区内自适应换行，但字段顺序不变，也不得将图片字段混入任务维度或改变两个维度的业务含义。

### 2. 任务维度查询

#### 2.1 普通搜索

现有任务维度普通搜索增加第三方任务 ID，仍使用单个输入值查询：

| 业务端 | 普通搜索匹配范围 |
|---|---|
| 美工版 | 系统 SKU、TaskID、第三方任务 ID |
| 运营版 | 店铺、ASIN、TaskID、第三方任务 ID |

普通搜索框提示文案同步调整为：

| 业务端 | 提示文案 |
|---|---|
| 美工版 | `搜索 SKU / TaskID / 第三方任务ID` |
| 运营版 | `搜索店铺 / ASIN / TaskID / 第三方任务ID` |

处理规则：

1. 第三方任务 ID精确匹配任务表 `externalTaskId`，覆盖 LinkFox、自研、阿里绘蛙生成来源。
2. 普通搜索输入值与当前页面支持的字段分别匹配，命中任一字段即可；新增第三方任务 ID不支持模糊、前缀或后缀匹配，原有字段继续沿用各自现网匹配规则。
3. 第三方任务 ID输入值去除前后空格，字段值不主动转换大小写；原有字段的输入处理继续沿用现网规则。
4. 同一输入值命中当前权限范围内多条任务时，返回全部匹配任务，不只取一条。

#### 2.2 批量搜索

在现有任务维度“批量”下拉中新增“第三方任务ID”，对应任务表 `externalTaskId`。两版字段顺序如下：

| 业务端 | 批量字段顺序 |
|---|---|
| 美工版 | TaskID / 第三方任务ID / 系统SKU |
| 运营版 | TaskID / 第三方任务ID / ASIN / 店铺 |

原有 `TaskID` 文案、默认值和查询逻辑保持不变。页面重置后，任务维度批量字段仍恢复为 `TaskID`。

### 3. 图片维度查询

图片维度在保留模型、图片类型、侵权禁售检测、AI生成人物检测等现有筛选的基础上，新增普通搜索和独立的批量搜索组件。

#### 3.1 普通搜索

图片维度普通搜索为单值精确查询，一个输入框同时匹配以下三个字段，命中任一字段即可：

输入框提示文案为：`搜索图片名 / 第三方图片ID / 第三方ID`。

| 查询项 | 数据来源 | 查询规则 |
|---|---|---|
| 图片名 | 图片表 `uniqueId` | 直接精确匹配独立落库的图片名，不从 `imageUrl` 截取或解析 |
| 第三方图片 ID | 图片表 `externalImageId` | 精确匹配；同一 ID命中多张图片时返回全部匹配图片 |
| 第三方ID | 任务表 `externalTaskId` + `_` + 图片表 `externalImageId` | 按图片所属任务关联，精确匹配两个字段的完整拼接结果，不新增组合落库字段 |

普通搜索输入值去除前后空格，不主动改变大小写。图片名、第三方图片 ID或组合第三方 ID存在重复时，返回当前权限及全部筛选条件范围内的所有匹配图片。

#### 3.2 批量搜索

图片维度新增与任务维度相同的批量搜索组件，批量字段顺序和默认值如下：

| 顺序 | 批量字段 | 数据来源 |
|---:|---|---|
| 1 | 第三方ID | `externalTaskId` + `_` + `externalImageId`，默认值 |
| 2 | 第三方图片ID | 图片表 `externalImageId` |
| 3 | 图片名 | 图片表 `uniqueId` |

页面重置后，清空图片维度普通搜索和批量值，图片批量字段恢复为“第三方ID”。

#### 3.3 图片命中和任务展示

1. 图片维度普通搜索、批量搜索和其他图片筛选均只保留命中的图片，不展示同一任务下未命中的其他图片。
2. 一个任务下全部图片均被图片维度条件剔除时，该任务不展示。
3. 最终任务数量、分页、状态子 Tab数字及任务内统计各自沿用现网对图片维度筛选的既有计算规则；本期不因新增搜索改变统计口径。

### 4. 第三方字段和历史数据

| 业务含义 | 表及字段 | 适用范围 |
|---|---|---|
| 第三方任务 ID | 任务表 `externalTaskId` | LinkFox、自研、阿里绘蛙 |
| 第三方图片 ID | 图片表 `externalImageId` | LinkFox、自研、阿里绘蛙 |
| 图片名 | 图片表 `uniqueId` | 全部图片 |
| 图片 URL | 图片表 `imageUrl` | 继续用于图片展示，不作为图片名查询来源 |
| LinkFox子模型 | 图片表 `subModelType` | LinkFox图片 |

处理规则：

1. 研发需分别核对美工版、运营版接口和数据表中以上字段的实际类型、关联关系及空值表现，不得仅根据字段名称猜测。
2. `externalTaskId`、`externalImageId` 如为超长数字或可能超过前端安全整数范围，接口传输、前端输入和查询参数均按字符串处理，不得发生精度丢失。
3. 组合第三方 ID沿用 L3现有格式 `第三方任务ID_第三方图片ID`，按图片所属任务的 `externalTaskId + "_" + externalImageId` 完整拼接结果整体精确匹配，不以某个下划线位置拆分后匹配；原始 ID包含下划线时仍按完整拼接结果查询，同一组合值命中多张图片时返回全部匹配图片。
4. 历史任务和图片不专项回刷或补数，只查询当前已经落库的数据；正常已有数据继续按原记录查询。
5. 字段为空时不命中对应普通或批量搜索条件，不报错、不影响其他记录查询。
6. 输入格式不正确、单个批量值未命中或全部值未命中时，不增加字段格式报错；未命中的值不返回结果，全部未命中时沿用页面现有空状态。

### 5. 批量搜索组件规则

任务维度和图片维度均复用现有批量搜索组件及交互：

1. 英文逗号、中文逗号、换行和 Tab作为分隔符；空格不作为分隔符，仅去除每个值前后空格。
2. 按“拆分、去除前后空格、过滤空值、原始字符串完全一致去重”的顺序解析，前端不主动转换大小写。
3. 任务维度和图片维度的批量组件分别计算上限，每个组件最多支持 `500` 个去重后的有效值；两者同时使用时最多可合计提交 `1000` 个有效值，不设置跨组件合计 `500` 条限制。任一组件超过自身上限时保留输入但禁止查询，不自动截断、不自动分批，并在对应组件提示 `超出上限：X / 500`。
4. 批量浮层为空时点击“应用并查询”，不查询、不关闭浮层，提示“请输入批量搜索内容”；页面直接查询且批量值为空时忽略该批量条件。
5. 切换批量字段时保留已输入内容，不自动查询；下次查询按切换后的字段解释当前输入值。
6. 普通搜索框和批量外层输入框按 Enter触发查询；批量浮层 textarea 内按 Enter只换行。
7. 点击“清空”只清空当前批量值，不立即查询；点击“应用并查询”回写批量值并按页面当前全部筛选条件查询。
8. 页面查询后回到第1页；结果排序不按批量值输入顺序调整，继续沿用页面当前排序。
9. 任务维度和图片维度的批量字段、输入值及浮层内容分别保存，可以同时作为查询条件，互不覆盖。
10. 同一时间只打开一个批量输入浮层。打开另一维度的批量浮层时，先将当前浮层内容回写外层并关闭，但不自动查询，再打开目标浮层。
11. 点击页面【查询】或任一浮层“应用并查询”时，读取任务维度和图片维度两个批量组件的最新值，并与页面其他条件共同查询；页面重置同时清空两个组件的值，再分别恢复各自默认字段。

### 6. 查询组合和权限

查询关系统一如下：

| 条件组合 | 关系 |
|---|---|
| 任务维度普通搜索框支持的多个字段 | OR；第三方任务 ID精确匹配，原有字段沿用各自现网匹配规则 |
| 图片维度普通搜索框支持的多个字段 | OR，任一字段精确命中即可 |
| 同一个批量字段内的多个有效值 | OR，任一值精确命中即可 |
| 同一维度的普通搜索与批量搜索 | AND |
| 任务维度普通搜索、任务批量搜索及其他任务筛选 | AND |
| 图片维度普通搜索、图片批量搜索及其他图片筛选 | AND |
| 任务维度条件与图片维度条件 | AND |

例如运营版普通搜索输入店铺、任务批量字段选择 ASIN时，查询指定店铺且 ASIN命中批量任一值的任务；图片普通搜索和图片批量搜索同时存在时，两者也共同收敛最终图片结果。

所有查询继续遵循以下规则：

1. 当前时间范围继续生效，使用第三方任务 ID、第三方图片 ID或组合第三方 ID查询较早数据时，用户需要先调整时间范围。
2. 后端先按当前登录用户的数据权限和当前业务端裁剪，再应用任务维度和图片维度条件；无权限数据不返回，也不因批量值包含无权限数据导致整个查询失败。
3. 美工版只能查询美工版数据，运营版只能查询运营版数据，不得跨业务端混查。
4. 当前状态子 Tab、创建人、任务图张数、模型、图片类型、检测状态等现有条件继续生效。

### 7. LinkFox子模型筛选

图片维度在主模型筛选后新增“LinkFox子模型”字段，规则如下：

1. 字段始终显示；主模型未选择 LinkFox 时置灰，提示“请先选择LinkFox”，不参与查询。
2. 主模型选择 LinkFox 后启用，默认值为“全部子模型”。
3. 从 LinkFox切换为全部模型、自研或阿里绘蛙时，自动清空具体子模型条件并恢复“全部子模型”。
4. 选择具体子模型时，精确匹配图片表 `subModelType`；研发需使用现有子模型字典核对实际枚举值与页面文案映射。
5. “全部子模型”包含 `subModelType` 为空或无法识别的 LinkFox图片；选择具体子模型时，空值和其他未知值不命中。
6. 不新增“未知子模型”筛选项，不回刷历史 `subModelType`。

筛选项使用现有8个 LinkFox子模型的业务名称：

1. 谷歌香蕉1Pro
2. 谷歌香蕉2
3. GPT图片2低品质
4. GPT图片2中品质
5. GPT图片2高品质
6. LinkFox自研模型V1
7. 万相2.7
8. Seedream 5.0 Pro

### 8. 接口、性能和兼容要求

1. 美工版、运营版查询接口分别实现新增任务查询、图片查询和 LinkFox子模型筛选，不得只改其中一版。
2. 新增批量字段通过后端白名单或枚举映射到固定查询字段，不允许直接使用前端传入字段名拼接查询。
3. 批量查询应使用集合查询能力，不得逐条循环查询；任务维度和图片维度各输入500个有效值并同时生效时，也必须按两个批量集合共同查询。
4. 研发需逐一检查两版任务表 `externalTaskId`、图片表 `externalImageId`、`uniqueId`、`subModelType` 及任务图片关联键的现有索引和查询计划；缺少适用索引时在本需求内补充后再上线。
5. 原有普通搜索字段、批量字段、参数含义、查询结果、排序和权限规则保持不变；`TaskID` 文案及默认值保持不变。
6. 页面重置除新增字段按本文恢复默认值外，其他筛选项继续沿用现有重置规则。
7. 两版接口提测前，在现有接口文档中分别补充任务与图片普通搜索范围、两个批量字段枚举及多值参数、`500` 条上限、LinkFox子模型参数、字段类型、默认值、空值处理和请求示例；两版参数命名可按各自现有接口规范实现，但业务含义和处理规则必须一致。

### 9. 本期边界

- 不新增或调整左侧菜单、页面路由、状态子 Tab、列表卡片、图片卡片、分页器及 L3沉浸式大屏展示。
- L3现有图片名、第三方任务 ID、第三方图片 ID、组合第三方 ID及 LinkFox子模型信息继续按现状展示和复制，本期不重复开发。
- 不修改 AI 生图任务创建、编辑、复制重跑、L2审核工作台、普通任务列表、BI或其他未列明页面。
- 不新增角色、菜单权限或按钮权限，只沿用现有页面访问和数据权限。
- 不新增模糊搜索、自动扩大时间范围、跨业务端查询、历史数据回刷或第三方接口重新查询。

## 风险描述

| 风险 | 处理方式 |
|---|---|
| 两版接口分别实现，可能出现字段、筛选关系或异常处理不一致 | 两版使用同一产品规则和验收集逐项核对，分别完成接口及页面验收。 |
| 第三方 ID可能超过前端安全整数范围 | 核对字段类型并按字符串传输、输入和查询，禁止数值转换导致精度丢失。 |
| 组合第三方 ID拼接或任务图片关联错误 | 不新增拼接落库字段，按真实任务图片关系生成完整拼接结果后整体精确匹配，不依赖固定下划线位置拆分。 |
| 两个批量组件各输入500个值时查询量增加 | 使用两个批量集合共同查询，逐一确认目标字段和关联键索引，缺少时本需求内补充；不得形成逐条循环或两个集合的无条件笛卡尔遍历。 |
| `subModelType` 枚举与页面名称映射不一致 | 研发按现有子模型字典核对8个选项，使用真实枚举精确查询。 |
| 图片维度搜索被误实现为返回所属任务全部图片 | 图片维度只保留命中图片，无命中图片的任务不展示。 |
